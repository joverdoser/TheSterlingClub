Accessibility Statement

Updated October 30, 2026

The Sterling Club wants everyone to be able to use this website, including people who use screen readers, keyboards, or other assistive technology.

Our goal

We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA. Steps we have taken include:

  • Every page can be used with a keyboard, with visible focus outlines and a "Skip to content" link
  • Images have text descriptions, and decorative images are hidden from screen readers
  • Text and buttons are checked for color contrast
  • Form fields have labels, required fields are marked, and errors are announced
  • There are no moving slideshows, and animation is turned off if your device is set to reduce motion

Known limitations

We test this website with automated tools and by hand, but some parts may still be hard to use. We are working to improve them.

Need help or found a problem?

If you have trouble using any part of this website, contact us and we will help you get the information or service you need another way, such as by phone. Please also tell us about the problem so we can fix it.
